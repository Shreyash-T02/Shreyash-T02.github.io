Projects

  • 2026.04 - Present
    UR20 Washing Machine Assembly Cell (MuJoCo + ROS 2)
    A full ROS 2 Humble simulation of a UR20 manipulator performing top-load washing machine assembly, with physics in MuJoCo 3.x through the mujoco_ros2_control plugin. Implemented DH forward kinematics, a geometric Jacobian with live manipulability reporting, and a damped least-squares IK solver converging to sub-millimeter position error. Fully containerized for reproducibility.
    • ROS 2 Humble
    • MuJoCo 3.x
    • ros2_control
    • Damped least-squares IK
    • Jacobian & manipulability
    • Docker
  • 2025.09 - 2025.12
    Autonomous Mobile Robot: Localization, Planning & Control
    Implemented a particle filter localizer on a known 2D map using LIDAR scan matching and low-variance resampling, achieving pose convergence within a few exploratory motions in Gazebo and RViz. Built an RRT motion planner with obstacle-padded collision checking, shortcut smoothing, waypoint densification, and a reactive safety layer monitoring forward LIDAR returns. Deployed a dual-axis PID controller for heading and velocity regulation inside a closed sense-plan-act loop that corrected odometry drift in real time.
    • Particle filter localization
    • LIDAR scan matching
    • RRT motion planning
    • Path smoothing
    • Dual-axis PID
    • ROS / Gazebo / RViz
